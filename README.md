# JavaScript Piscine — Checkpoint 1

This repository contains my work for the **1st JavaScript Checkpoint** in the
JS Piscine. The README will be updated as I progress through each checkpoint,
up to the final checkpoint.

## Checkpoint 1 exercises

The exercises are organized by level:

- **Level 1:** sum even numbers, calculate factorials, and find Fibonacci numbers.
- **Level 2:** find proper divisors and check for perfect numbers.
- **Level 3:** build palindromic chains and print sentence pyramids.
- **Level 4:** reverse array chunks and nested arrays.
- **Level 5:** sort an array with insertion sort and report comparisons and swaps.

See [FUNCTIONS.md](FUNCTIONS.md) for explanations of the functions and
algorithms used in the exercises.

## Running an exercise

Each exercise is a standalone JavaScript file with example calls. With Node.js
installed, run a file from the repository root, for example:

```sh
node level1/fibonacci.js
```

Replace the file path with the exercise you want to run.
